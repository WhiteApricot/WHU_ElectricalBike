# 算法目录说明

本目录用于存放后续真实算法实现代码。

当前状态：
- 只提供算法文件骨架、函数签名和详细中文注释。
- 不实现任何具体算法逻辑。
- 所有函数默认抛出 `NotImplementedError`，等待算法负责人补充实现。

## 文件划分建议

- `siting_optimization.py`
  用于实现停车点智能选址相关算法，例如遗传算法（GA）、粒子群优化（PSO）、NSGA-II 等。

- `manual_evaluation.py`
  用于实现人工调整停车点后的实时评估逻辑，例如覆盖率、平均步行距离、均衡性重算。

- `demand_prediction.py`
  用于实现需求预测模型，例如基于时空序列或神经网络的站点需求预测。

- `dispatch_routing.py`
  用于实现调度路径优化算法，例如蚁群算法（ACO）、遗传算法（GA）等。

- `base.py`
  用于定义算法模块通用的返回约定或辅助类型。

## 开发约束

1. 所有算法入口函数的返回值，必须与当前后端 API 响应模型兼容。
2. 如果前端需要展示算法中间过程，算法实现应额外输出迭代状态，并转换为过程接口可读取的统一格式。
3. 不要在算法文件中直接耦合 FastAPI 路由逻辑，算法层只负责输入计算和输出结构。
4. 若后续改为异步任务或消息队列，这些函数仍应保持“纯算法/纯服务”职责，避免混入接口层逻辑。
